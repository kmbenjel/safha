# قصّ كتاب كامل

## الأمر الأساسي

```bash
safha crop book.pdf -o book-phone.pdf --jobs 4
```

- `--jobs` عدد العمليات المتوازية؛ النتيجة واحدة مهما كان العدد.
- `--recipe book.json` يحفظ الوصفة (قرارات كل صفحة) لمراجعتها أو إعادة تطبيقها.
- `--sheet book.jpg` يكتب صورة «قبل | بعد» لأهمّ الصفحات.

## ماذا تفعل الأداة بكل صفحة؟

1. **تقيس** كل صفحة كما يعرضها القارئ، ولو خُزّنت في الملف على جنبها: تميّز النص عن غيره، فتُبقي الحواشي والأرقام
   والجداول والإطارات المطبوعة داخل الإطار، وتُخرج أشرطة الماسح وسطحه الأسود وظلال الحواف والنقط المعزولة والبقع.
2. **تقيس الميل** بمقياسين، ثم تستشهد عليه بما في الصفحة: تتبّع كل سطر على حدة، وتنظر في حدَّي النص وفي خطوطه
   المطبوعة. إن كانت أسطر الصفحة على زاويتين (ورقة متموّجة) أو اختلف الشهود تُركت كما صُوّرت، لأن أي تدوير سيُميل
   ما كان مستويًا. وصفحة العمودين تُدار بالخطّ المطبوع بين عموديها إن وُجد.
3. **تختار إطارًا واحدًا للكتاب** يسع نص الصفحات المعتادة مع هامش، ثم تضعه على نص كل صفحة. والورقة التي مقاسها غير
   مقاس الكتاب (لوحة أو خريطة) تُعرض كاملةً مصغّرة.
4. **تتحقق** بدقة أعلى من أنّ شيئًا من النص لم يُقطع: تقرأ صورة الصفحة نفسها حول حدّ الإطار، فإن مرّ الحدّ بحرف أو
   بسطر أو بحاشية تمتدّ إلى طرف الورقة حرّكت الإطار قليلًا أو كبّرته أو أبقت الصفحة كاملة.
5. **تكتب** الملف دون مساسٍ بالصور، ثم تتحقق من عدد الصفحات ومن أنّ كل صورة بقيت كما هي ومن أنّ المقاس واحد. ولا يأخذ
   الملف الناتج اسمه إلا بعد نجاح هذا التحقق.

## خيارات شائعة

| الخيار | معناه |
|---|---|
| `--rtl` / `--ltr` | ترتيب الصفحتين عند فصل الصفحات المزدوجة |
| `--split never` | لا تفصل الصفحات العريضة (خرائط، جداول) |
| `--no-deskew` | لا تدِر أي صفحة |
| `--always` | اقصص حتى الكتاب الجيد التصوير |
| `--set min_text_pages=3` | اقصص كتابًا قصيرًا (الأداة تترك ما دون خمس صفحات نص) |
| `--drop 1,2` | احذف هذه الصفحات أيضًا (غلاف خارجي، صفحة بيضاء) |
| `--compact` | أعد كتابة الملف كله (أصغر قليلًا، لكنه لا يُسترجع بالبتر) |

## عدّة كتب

تعالج الأداة كتابًا واحدًا في كل تشغيل. ولمجلد كامل استعمل حلقة في الصدفة:

```bash
for f in books/*.pdf; do safha crop "$f" -q; done
```

## على مراحل: الوصفة أولًا

```bash
safha plan book.pdf -o book.recipe.json --pretty
safha inspect book.recipe.json
safha apply book.pdf book.recipe.json -o book-phone.pdf
```

الوصفة ملف JSON مقروء: لكل صفحة نوعها وزاوية تدويرها والجزء الظاهر منها وملاحظاتها. يمكن تعديلها يدويًّا ثم تطبيقها.
