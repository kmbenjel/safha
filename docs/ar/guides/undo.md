# التراجع واسترجاع الأصل

لا تكتب safha فوق الملف الأصلي أبدًا. والملف الذي تُخرجه يبدأ ببايتات الأصل كلها كما هي، ثم تُلحَق بها التعديلات
(تحديث تزايدي في لغة PDF). لذلك يُسترجع الأصل من الناتج وحده:

```bash
safha restore book.safha.pdf -o book-original.pdf
```

يبتر الأمر الملف عند طول الأصل، ثم يتحقق من بصمته (MD5) المحفوظة في الملف قبل أن يكتبه.

!!! warning "تنبيه"
    الخيار `--compact` يعيد كتابة الملف كله فيصغر قليلًا، لكنه لا يُسترجع بهذه الطريقة. احتفظ بالأصل إن استعملته.
    وكذلك الملف التالف الذي أُصلحت بنيته عند القراءة: يُكتب ناتجه كاملًا، وتنبّهك الأداة إلى ذلك في حينه.

## حذف الصفحات

```bash
safha drop book.pdf --pages 1,2 -o book-numbered.pdf
safha drop book.pdf --blank -o book-numbered.pdf
```

لا تحذف الأداة صفحة فيها حبر إلا بالخيار `--force` (غلاف خارجي مثلًا)، والحذف أيضًا قابل للاسترجاع بالأمر نفسه.
وسواد سطح الماسح حول ورقة بيضاء ليس حبرًا: تُعدّ الورقة فارغة.
وإن أردت أن تكون كل خطوة في مكتبتك مخططةً ومسجّلةً وقابلةً للتراجع، فانظر في أداة [planfs](/planfs/).
